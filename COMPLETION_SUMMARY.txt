🚀 NEXT STEPS (in order)

1. CREATE CONTENTFUL ACCOUNT (5 minutes)
   - Go to www.contentful.com
   - Sign up (free tier available)
   - Create a Space
   - Get your Space ID

2. GENERATE API TOKENS (2 minutes)
   - Settings > API Keys
   - Create Content Delivery token
   - Settings > API Tokens
   - Create Personal Access token

3. CONFIGURE ENVIRONMENT (1 minute)
   - Copy .env.example to .env
   - Fill in 4 Contentful values
   - Don't commit .env!

4. INITIALIZE CONTENTFUL (30 seconds)
   - pnpm run contentful:setup
   - pnpm run contentful:seed

5. START DEVELOPMENT (1 minute)
   - pnpm run dev
   - Visit http://localhost:3000
   - You should see your portfolio!

6. DEPLOY TO NETLIFY (10 minutes)
   - Push to GitHub
   - Connect to Netlify
   - Add environment variables
   - Deploy!

🔒 SECURITY REMINDERS

✅ DO:
  - Keep .env file safe
  - Never commit .env to git
  - Use read-only tokens in production
  - Use environment variables on Netlify

❌ DON'T:
  - Share your .env file
  - Commit tokens to GitHub
  - Use management tokens in CI/CD
  - Expose secrets in build logs

❓ QUICK TROUBLESHOOTING

Error: "Expected parameter accessToken"
→ Solution: Fill in .env with Contentful tokens

Projects not showing
→ Solution: Run pnpm run contentful:seed

Changes not appearing
→ Solution: Run pnpm run build

Port 3000 in use
→ Solution: Change port in astro.config.mjs

Can't find Contentful tokens
→ Solution: Check Contentful Settings > API Keys
